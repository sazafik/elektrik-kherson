# ⚡ Електрик Херсон | Сайт послуг електрика

Сучасний, адаптивний, швидкий сайт послуг електрика у місті **Херсон**, створений за типом `elektrik.kiev.ua`, але з оновленим преміальним дизайном, актуальними ринковими цінами на 2024–2026 роки, безпечним підключенням резервного живлення (EcoFlow / генератори), інтерактивним калькулятором вартості та підтримкою оновлення через **Git / GitHub Pages**.

---

## 🌟 Основні переваги та можливості

1. **Адаптований під Херсон**:
   - Всі райони міста: *Таврійський (1-4), Шуменський, Центр, Дніпровський, Корабельний (Острів), ХБК, Житлоселище, Північний*, а також пригород (*Антонівка, Чорнобаївка, Степанівка*).
   - Актуальні тарифи в гривнях (від 90 грн за розетку, від 250 грн за люстру, від 280 грн за реле ZUBR, від 450 грн за перемикач резерву).
2. **Блок резервного живлення (EcoFlow, генератори, інвертори)**:
   - Вкрай актуальна послуга для України. Безпечна комутація через перемикач I-0-II без небезпечної схеми «вилка-вилка».
3. **Двомовність (UA / RU)**:
   - За замовчуванням українська мова (вимога законодавства), з миттєвим перемикачем на російську мову в один клік без перезавантаження сторінки.
4. **Інтерактивний прайс-лист з живим пошуком та фільтрами**:
   - Миттєвий пошук послуг за назвою (наприклад: *люстра*, *автомат*, *реле*).
   - Вкладки за категоріями робіт.
5. **Живий калькулятор вартості**:
   - Клієнт обирає кількість точок або послуг (+ / -), бачить попередню вартість і в 1 клік надсилає готовий список прямо в **Telegram** або **Viber** майстра!
6. **Мобільна плаваюча панель (Mobile Bottom Bar)**:
   - Для швидкого дзвінка або зв'язку в месенджерах на смартфонах (80%+ трафіку).
7. **SEO оптимізація**:
   - Schema.org (LocalBusiness / Electrician) мікророзмітка, OpenGraph теги для красивих посилань у соцмережах та месенджерах.

## ⚙️ Як легко оновлювати ціни та контакти

Всі контакти, телефони, месенджери та ціни винесені в один простий файл:
👉 `data/site-config.js`

Вам **не потрібно** розбиратися в HTML-коді! Щоб змінити будь-яку ціну чи телефон:
1. Відкрийте `data/site-config.js`.
2. Відредагуйте потрібний номер або ціну:
   ```javascript
   contacts: {
     phonePrimary: "+38 (095) 123-45-67",
     phonePrimaryRaw: "+380951234567",
     telegramUsername: "vash_telegram",
     ...
   }
   ```
3. Для зміни цін просто поміняйте цифри:
   ```javascript
   {
     id: "out_1",
     name: { ua: "Монтаж розетки", ru: "Монтаж розетки" },
     price: 100, // <--- нова ціна
     priceText: { ua: "від 100 грн", ru: "от 100 грн" },
     ...
   }
   ```
4. Збережіть файл і відправте зміни на Git (`git commit` + `git push`). Сайт оновиться автоматично!

## 🚀 Як запустити на GitHub (GitHub Pages безкоштовно)

Сайт працює на чистому HTML/CSS/JS без важких залежностей. Його можна хостити безкоштовно на **GitHub Pages** або **Vercel / Netlify**.

### Крок 1. Ініціалізація та відправка коду на GitHub
Відкрийте термінал у папці проекту:

```bash
# 1. Ініціалізуємо репозиторій
git init

# 2. Додаємо файли
git add .

# 3. Робимо перший коміт
git commit -m "Перший реліз сайту Електрик Херсон"

# 4. Перейменовуємо гілку в main
git branch -M main

# 5. Підключаємо ваш віддалений репозиторій на GitHub
# (замініть USERNAME та REPO на ваші дані):
git remote add origin https://github.com/USERNAME/REPO.git

# 6. Відправляємо на GitHub:
git push -u origin main
```

### Крок 2. Увімкнення GitHub Pages у 2 кліки

1. Перейдіть у ваш репозиторій на GitHub.
2. Відкрийте вкладку **Settings** (Налаштування) -> у лівому меню виберіть **Pages**.
3. У розділі **Build and deployment**:
   - **Source**: оберіть **GitHub Actions** (готовий файл `.github/workflows/deploy.yml` вже є в репозиторії і розгорне сайт автоматично!)
   - Або оберіть **Deploy from a branch** -> гілка `main` -> папка `/ (root)` -> натисніть **Save**.
4. Зачекайте 30–60 секунд: ваш сайт стане доступним за безкоштовною адресою:
   `https://USERNAME.github.io/REPO/`

### Крок 3. Підключення власного домену (опціонально)
Якщо ви придбаєте домен (наприклад `elektrik-kherson.com.ua` чи `elektrik.ks.ua`):
1. У **Settings -> Pages -> Custom domain** впишіть свій домен.
2. Встановіть галочку **Enforce HTTPS** (безкоштовний SSL сертифікат безпеки).

## 🛠️ Локальний перегляд
Щоб подивитися сайт на комп'ютері:
